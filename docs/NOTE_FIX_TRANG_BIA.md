# GHI CHÚ: Sửa trang bìa khóa luận

## Vấn đề
File `khoaluan1.pdf` trang 2 (trang bìa phụ) đang **thiếu thông tin** ở các trường:
- SV thực hiện: (trống)
- Chuyên ngành: (trống)
- MSSV: (trống)

## Cần sửa thành

```
SV thực hiện    : Trịnh Hoàng Tú, Trần Minh Thiện
Chuyên ngành    : An ninh mạng
MSSV            : 23DH113972, 23DH113375
Khóa            : Khóa 29 – K29
GVHD            : Ths Cao Tiến Thành
```

## Cách sửa
Mở file Word gốc (`KhoaLuanTotNghiep.docx`) → sửa trang bìa 2 → xuất lại PDF.

Hoặc nếu không có file Word: dùng Adobe Acrobat / Foxit PDF Editor để chỉnh sửa trực tiếp text trên PDF.
